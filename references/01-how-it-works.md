# 01 原理、和云服务器对比、域名准备

## 1. 为什么家里电脑平时「外网访问不到」

1. 家里宽带大多没有公网 IPv4：运营商把很多家庭放在同一个出口 IP 后面（运营商 NAT / CGNAT）。
2. 外面的人连不进来，因为没有一个「属于你家」的地址可以连。
3. 传统做法是租一台有公网 IP 的云服务器，把服务放上去；或者做内网穿透（frp 等），也要一台有公网 IP 的中转机。

## 2. Cloudflare Tunnel 怎么绕过这个问题

```
① 家里电脑上的 cloudflared 主动连出去 ──► Cloudflare 边缘（一般建 4 条连接，分到 2 个机房）
② 访客访问 https://blog.example.com   ──► DNS 指向 Cloudflare
③ Cloudflare 把请求顺着 ① 建好的连接送回家里 ──► cloudflared 转给 127.0.0.1:3000
```

1. 连接方向是「从家里往外」。出站连接家家都能建，所以不需要公网 IP，也不用在路由器上开端口。
2. Cloudflare 相当于替你承担了「有公网 IP 的那台机器」，而且免费。
3. HTTPS 证书在 Cloudflare 边缘签发和续期。家里的服务只跑普通 http 就行。
4. 你家的真实 IP 不会暴露给访客。

## 3. 把域名交给 Cloudflare 管

1. 注册 Cloudflare 账号（免费），开两步验证。
2. 控制台 → Add a domain → 输入你的域名 → 选 Free 计划。
3. Cloudflare 给你两个 NS 地址（形如 `xxx.ns.cloudflare.com`）。
4. 到买域名的地方（阿里云、腾讯云、Namecheap 等）把域名的 DNS 服务器改成这两个。
5. 等状态变成 Active（几分钟到 24 小时）。之后这个域名的 DNS 都在 Cloudflare 里改。

> 国内注册商的域名也能托管到 Cloudflare。注意：发布网站不等于备案。走 Cloudflare 海外节点、源站在家里，作者的做法没有涉及备案；你的情况请自行了解当地规定。

## 4. 和云服务器、其他方案对比

| 方案 | 要公网 IP | 月费 | HTTPS | 国内速度 | 适合 |
|---|---|---|---|---|---|
| 云服务器 | 自带 | 有 | 自己配 | 快 | 正式业务、要国内秒开 |
| 家里电脑 + Cloudflare Tunnel | 不要 | 0 | 自动 | 一般（海外节点） | 个人网站、自用工具、接口 |
| 家里电脑 + frp + 云服务器中转 | 中转机要 | 有 | 自己配 | 看中转机 | 要裸 TCP / UDP 端口 |
| Tailscale / ZeroTier 组网 | 不要 | 0 | 不需要 | 看打洞是否成功 | 只给自己设备用，不对公众开放 |

本仓库解决的是第 2 行：**把服务开放给任何人用浏览器访问**。只想自己的设备互相访问，用 Tailscale 更合适，两者可以同时用。

## 5. 它做不到什么

1. **裸 UDP / 任意 TCP 端口**：游戏服务器、Tailscale 自建中转（DERP）、需要固定端口的协议，访客端不装 cloudflared 就用不了。这类服务仍然需要一台有公网 IP 的机器。
2. **国内低延迟**：免费版走海外节点，国内打开会慢一些（作者实测首页 1.5～2 秒）。
3. **大流量下载站 / 视频站**：Cloudflare 免费版服务条款不鼓励用来分发大量非网页内容（视频、大文件）。做网页、接口没问题。
4. **家里停电断网**：访客会看到 Cloudflare 的 530 / 1033 错误页。重要的东西做好备份。
5. **上传大文件**：免费版单个请求体上限 100 MB。

## 6. 费用

- Cloudflare：Tunnel、DNS、Access（50 人内）都免费。
- 域名：每年几十元起，看后缀。
- 电费：Apple 芯片 Mac mini 官方公布的空闲功耗是个位数瓦；旧 Windows 电脑一般高一些，可以用插座电量计量一下。
